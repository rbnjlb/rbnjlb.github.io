Privacy policy

Grand Scheme Studio · effective November 13, 2026

Who uses this application

Grand Scheme Studio is a private tool used only by the owner of the YouTube channel The Grand Scheme to manage that channel. It is not offered to the public.

What data it accesses

With the owner's permission, given through Google's sign-in screen, the application uses the YouTube Data API and the YouTube Analytics API to access the owner's own channel: to upload and schedule its videos, set thumbnails, captions, titles and descriptions, read comments on its videos, and read the channel's statistics (views, watch time, audience retention).

How the data is used and stored

  • The data is used only to publish the channel's videos and to improve future videos.
  • The access token is stored only on the owner's own computer. Statistics are kept in the owner's private production files.
  • No data about other people is collected. No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time from the Google account's security page: myaccount.google.com/permissions.

Third-party services

This application uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Contact

For any question about this policy, contact the channel through its YouTube page: youtube.com/@thegrandschemefiles/about.
